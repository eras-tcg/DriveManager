# Bot `guiado`: reporte de trabajo al 2026-11-11

Para retomar el trabajo en otro equipo. Rama `fix/nombres-impresos` de DriveManager.

## Objetivo

Simplificar y mejorar el modelo del bot. Tres fallos concretos que se veían en partidas:

1. **Ataques suicidas**: ataca regalando la criatura.
2. **Utilidades sin ventaja**: juega cartas y efectos que no le dan nada.
3. **Staleo y hardplay**: invoca criaturas normales en vez de invocaciones especiales, y se queda con una mesa de un solo cuerpo.

Además, el modelo era ininteligible: parámetros muertos y heurísticas que empujan lo mismo.

## Cómo se trabaja (acuerdos con el dueño)

- Se trabaja sobre **`guiado`**. Los niveles (fácil, normal, difícil) son recortes de él y no se tocan. `guiado-previo` es el `guiado` anterior, solo para duelos de comparación.
- `winFlat=1` se mantiene.
- **No se corren tandas de partidas para ver si un cambio funciona.** Se lee UNA partida turno a turno con el registro de decisiones, se encuentra el error visible, se explica con el modelo por qué el bot lo eligió y se corrige la causa. Después se recrea esa partida.
- Dos parámetros que compiten solo se justifican si son de distinta naturaleza. Varios que refuerzan el mismo observable sobran.
- Una recreación no prueba un arreglo: la misma semilla sale distinta de una corrida a otra, porque la búsqueda tiene presupuesto de tiempo.
- En el Mac no hay Java: todo se compila en Docker (`maven:3.9-eclipse-temurin-21`).

## Cómo recrear una partida

Desde `drive_manager/`, después de `publishToMavenLocal` en `eras-engine/`:

```bash
NEW=$(grep '^guiado|' src/main/resources/bot/models.txt | cut -d'|' -f3)
OLD=$(grep '^guiado-previo|' src/main/resources/bot/models.txt | cut -d'|' -f3)
mvn test -Dtest=BotDuelRun -Dbot.duel=true -Dbot.duel.pairs=st1-st2 -Dbot.duel.seeds=1 \
  -Dbot.duel.log=true -Dbot.duel.out=/tmp/duels "-Dbot.duel.a=$NEW" "-Dbot.duel.b=$OLD"
```

Con `-Dbot.duel.log=true` cada decisión de A sale como `> A decide <tipo> <carta> (opción i de n, espera X, ahora Y)`: `espera` es lo que proyecta y `ahora` el puntaje de la mesa actual.
